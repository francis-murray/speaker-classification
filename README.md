# Gender and Speaker classification

A data science project focused on classifying speakers using machine learning techniques applied to audio files from the LibriSpeech corpus.

## Overview

This project contains two classification tasks:

1. **Gender Classification** - Binary classification to predict the gender of a speaker using MFCC (Mel-frequency cepstral coefficients) features
2. **Speaker Classification** - Multi-class classification to identify individual speakers using wav2vec 2.0 features

## Dataset

The project uses OpenSLR's [LibriSpeech corpus](http://www.openslr.org/12/), specifically the `dev-clean` subset containing audio files from 40 speakers labeled by gender.
